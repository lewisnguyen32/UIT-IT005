# 2.3. Lời gọi hệ thống

Nguồn chính: **W02 slide 36–40**, chữ ở slide 36–37; các hình luồng gọi ở slide 38–40 cần xem gốc khi hỏi theo sơ đồ.

## Khái niệm và từ cần nhớ

| Khái niệm (English) | Định nghĩa/dấu hiệu |
|---|---|
| Lời gọi hệ thống (system call) | Giao diện để tiến trình yêu cầu các dịch vụ của hệ điều hành. Ví dụ thao tác mở/đọc/ghi file. Slide 36. |
| Giao diện lập trình ứng dụng (application programming interface / API) | Giao diện mà chương trình thường dùng để truy cập chức năng; slide nói phần lớn system call được truy cập thông qua API. Slide 36. |
| Thanh ghi (register / registers) | Một nơi truyền tham số của system call. Slide 37. |
| Vùng/khối bộ nhớ (memory block) | Có thể chứa tham số; địa chỉ vùng được gửi qua thanh ghi. Slide 37. |
| Ngăn xếp (stack) | Một cách khác để truyền tham số. Slide 37. |
| Mở tập tin (open) | Tên ví dụ thao tác mở file. Slide 36. |
| Đọc tập tin (read) | Tên ví dụ thao tác đọc dữ liệu. Slide 36. |
| Ghi tập tin (write) | Tên ví dụ thao tác ghi dữ liệu. Slide 36. |

## Các con số và tên riêng trong slide

- **3 phương pháp truyền tham số:** qua thanh ghi (registers); qua khối bộ nhớ và truyền địa chỉ bằng thanh ghi (memory block); qua ngăn xếp (stack). Đây là ba cách, không phải bốn.
- **3 API thông dụng được slide liệt kê:** Win32 API cho Windows; POSIX API cho các hệ thống POSIX; Java API cho máy ảo Java (JVM). Đây là ba ví dụ trong slide, không khẳng định thế giới chỉ có ba API.

## Dễ nhầm

Giao diện lập trình ứng dụng (API) và lời gọi hệ thống (system call) không đồng nhất. Hãy nhớ chuỗi ý: chương trình dùng giao diện lập trình → yêu cầu dịch vụ hệ điều hành. Không suy ra mỗi hàm API đều phải tương ứng đúng một system call.

`system call` là tên chuẩn gồm hai từ. Nếu đề ghi “_____ call” thì từ điền là `system`. Nếu hỏi đầy đủ tên mà bắt đúng một từ, cần xem đề có chấp nhận viết tắt hay đã cho phần còn lại không.
