# Nhập môn Mạng máy tính — UIT

Tổng hợp tài liệu lý thuyết và đề thi giữa kỳ phục vụ ôn tập.

- **Lý thuyết/**: Tài liệu các chương.
- **Giữa Kỳ/**: Đề thi, câu hỏi ôn tập và đáp án qua các năm.
- **output/**: Kế hoạch và ghi chú ôn tập.

Tiếp tục ôn từ [memory.md](memory.md). Quy tắc làm việc ở [AGENTS.md](AGENTS.md).
Chi tiết câu trả lời và lịch sử học đã tách theo chương trong `memory/`; chỉ đọc phần cần dùng.
